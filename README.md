# 暮色酒店 · GOLDEN HOUR（中文版）

网页 FPS 游戏《暮色酒店》的中文版，包含完整的界面中文化与本地运行说明。

## 文件结构

```
index.html      页面入口（加载器、HUD 骨架、加载页）
dist/game.js    游戏构建产物
i18n-zh.js      运行时中文化层（英译中词典 + 动态 DOM 监听）
```

## 本地运行

需要通过 HTTP 服务访问（不能直接双击 `index.html`）：

```bash
npx serve .
```

然后打开 `http://localhost:3000/`。

## 中文化说明

没有改动压缩后的 `dist/game.js`，而是新增 `i18n-zh.js` 在 DOM 层翻译：

- 精确词典 + 带数字/名称的动态文案规则（比分、配件数、击杀数等）
- `MutationObserver` 持续覆盖动态生成的菜单、HUD、击杀信息与结算页
- 覆盖范围：主菜单、枪匠（配件/迷彩/武器描述）、设置（操作/鼠标/音频/画面/界面）、加载提示、HUD、记分板、暂停菜单、结算页、K9 提示、全部击杀勋章
- 3D 场景内的霓虹招牌（如 RESTAURANT、STAFF ONLY）属于贴图，不在本层处理范围
